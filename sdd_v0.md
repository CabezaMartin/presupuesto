# Especificación: PresupuestoEjemplo v0

## 1. Objetivo y contexto de negocio
Quiero poder hacer una aplicacion para controlar los gastos.
Quiero poder ingresar mis ingresos y los de mi pareja.
Y agregar los gastos fijos como alquiler, colegio de la nena, club mio, de la nena de la madre.
y otros gastos fijos y tambien gastos variables.
Quiero poder hacer un control de gastos y ver en que puedo ahorrar con el objetivo de comprar una casa.
Ingresar los ingresos del mes y ingresar los gastos el estado de cuenta de la tarjeta de credito.
y ver cuanto es posble ahorrar y cuanto estamos del objetivo

## 2. Usuarios
un usuario pero puede tener grupos con otros usuarios
o un usuario solo pero ingresar gastos e ingresos de un grupo familiar

## 3. Escenarios de usuario (historias)
El usuario ingresa el ingreso menusal
el usuario sube un gasto
el usuario sube el estado de cuenta de la tarjeta


## 4. Requisitos funcionales
El sistema debe permitir agregar ingresos
El sistema debe permitir agregar gastos, de forma manual o sacando fotos o adjuntando estados de cuenta del banco
El sistema debe separar lso gastos en categorias
El sistema debe mostrar el objetivo del ahorro a medida que se va ahorrando
El sistema debe guardar la interacion del cliente para que cuando vuelva a entrar esa info no se pierda
